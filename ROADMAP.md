# Roadmap

This roadmap is intentionally lightweight. It describes the direction of the public Core project without promising dates.

## Near Term

- Publish versioned Docker images to GitHub Container Registry.
- Improve the self-host quick start and production deployment guide.
- Add more platform setup examples for Telegram, RSS, VK, MAX, and LinkedIn.
- Expand frontend smoke coverage for self-host and hosted runtime modes.
- Keep API, bot, and frontend copy behind the i18n boundaries.

## Medium Term

- Stabilize the browser-safe `/api/app/*` surface for self-host deployments.
- Add clearer backup, restore, and upgrade runbooks.
- Improve observability defaults for metrics, logs, correlation IDs, and worker queues.
- Add optional packaged deployment profiles for common VPS setups.
- Document extension points for new fetchers, publishers, and AI adaptation flows.

## Community

- Mark approachable issues with `good first issue`.
- Prefer small, well-scoped pull requests with focused tests.
- Keep the public Core repository free of private hosted deployment logic.
