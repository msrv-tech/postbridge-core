# Content studio samples

These are real outputs from Postbridge's video-studio release acceptance:

- `generated-video.mp4`: a ten-second, two-scene native AI video from the 22 October 2026 pilot. The visual brief was content cards moving through a luminous bridge, with no people or product UI. The web copy is a silent 540×960 H.264 transcode with fast-start metadata.
- `generated-video-poster.jpg`: a frame from that video at two seconds.
- `generated-cover.jpg`: the generated cover from the 24 October 2026 studio acceptance.

The home page labels these as separate examples. They are not presented as outputs of a single automatic campaign. The text card is illustrative copy. Video playback is user-initiated and uses `preload="none"`.
