# Code of Conduct

## Our Pledge

We want Postbridge Core to be a welcoming, focused, and useful project for people building publishing automation.

Participants are expected to communicate with respect, assume good intent where reasonable, and keep discussions constructive and relevant to the project.

## Unacceptable Behavior

Unacceptable behavior includes harassment, threats, personal attacks, spam, doxxing, and repeated off-topic disruption.

## Enforcement

Project maintainers may edit, hide, lock, or remove content that violates this code of conduct. Maintainers may also limit participation when behavior repeatedly harms the project or its community.

## Reporting

Report conduct issues privately to the project maintainer. Include links, screenshots, or context when possible.
