# Support

Postbridge Core is an open-source project. Community support is handled in public GitHub channels so answers can help future users too.

## Where to Ask

- **Questions and setup help:** use GitHub Discussions.
- **Reproducible bugs:** open a bug report issue.
- **Deployment problems:** open a deployment help issue and include non-sensitive logs.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md). Do not open public issues for suspected vulnerabilities.

## What to Include

For faster help, include:

- Postbridge Core version, tag, or commit SHA;
- deployment method: Docker Compose, custom container platform, or source checkout;
- operating system and Docker versions;
- relevant `.env` variable names without values;
- sanitized logs with tokens, database URLs, channel IDs, and personal data removed.

## Scope

Community support covers the public Core runtime, self-host Docker Compose setup, public APIs, integrations, and documentation.

Private hosted deployments, billing, and private deployment overlays are outside the scope of this repository.
